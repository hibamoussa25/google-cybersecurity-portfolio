# Overview
In this project, I served as a cybersecurity analyst responding to a Distributed Denial of Service (DDoS) attack caused by a flood of ICMP packets entering the internal network and distributing traffic through an unconfigured firewall.

The attack caused a two-hour network outage, impacting internal resources and interrupting business operations. The incident response team mitigated the attack by blocking incoming ICMP packets, shutting down non-critical services, restoring critical systems, and investigating the root cause.

I created an incident report by analyzing the network incident using the National Institute of Standards and Technology's Cybersecurity Framework (NIST CSF) and the knowledge I gained throughout the course.

**Review **scenario.pdf** for more information on the incident.
