# Conducting a Security Audit
---
# Overview
This project focuses on completing an internal IT audit for Botium Toys, a small fictional U.S. business that develops and sells toys. A thorough review of the company's scope, goals, and risk assessment report has been completed to evaluate whether Botium Toys adheres to standards and best practices. I performed this internal audit by completing a controls and compliance checklist, then provided feedback to the organization that can help them significantly strengthen their organization and guarantee confidentiality.

---
# Objectives 
Utilize the resources provided to:
- Review Botium Toys' scope, goals, and risk assessment report
- Utilize the NIST CSF control categories to evaluate Botium Toys’ security framework.
- Complete a Controls and Compliance Checklist evaluating the company
- Provide recommendations to strengthen the organization's security framework.
