# Identifying Vulnerabilities for a Small Business
---
# Overview 
In this activity, I am serving as a newly hired cybersecurity analyst for an e-commerce company. I am tasked with completing a vulnerability assessment of the situation to communicate the potential risks to decision makers at the company. From this scenario, I created a written report that explains how the vulnerable server is a risk to business operations and how it can be secured.

---
# Objective 
The purpose of this activity is to:
- Analyze the vulnerabilities of a public remote database server
- Identify threat actors and threat events
- Evaluate risks using likelihood and severity scoring
- Document findings in a professional vulnerability assessment report
- Propose remediation steps aligned with security principles and organizational goals
  
---
# Skills 
From this activity, I gained the following skills:
- Risk Analysis
- Critical Thinking
- Strong Written Communication
