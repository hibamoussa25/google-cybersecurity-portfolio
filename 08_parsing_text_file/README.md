# Importing & Parsing a Text File in a Security-Related Scenario
---
# Overview 
In this project, I am serving as a security professional working at a healthcare company. My job is to regularly update a file that identifies the employees who can access restricted content. The “allow_list.txt” file showcases these employees based on their  IP addresses. There is also a remove list that identifies the IP addresses of employees who should no longer be able to access the content. I have created an algorithm that reads an existing allow list file, compares it to a remove list containing IP addresses that should no longer have access, and removes any matches.

---
# Objectives
Create an algorithm that:
- Reads an existing allow list file
- Converts string into a list
- Iterates through a remove list
- Removes IP addresses that are on the remove list
- Updates the file with the revised list of IP addresses
